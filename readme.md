# CEN437 Network Programming

## Project Overview
This project is an integrated network diagnostic and management utility created for the CEN437 Network Programming course. It brings together machine diagnostics, echo connection testing, SNTP time synchronization, socket configurations, and a multi-terminal chat application into a single command-line interface.
